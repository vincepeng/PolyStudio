# 回答：

## 问题 1：分析工作流

主要是在skills 里面定义(backend/skills/custom/video-creator/skill.md),第一步先进行需求分析，在分镜，在生图，在图生视频，再视频剪辑，最后进行检查。不过这里比较简单，例如分镜之前更好分镜剧本，生图里面分为角色图、道具图、场景图等，然后图生视频分为不同生产方式，例如首尾帧。剪辑也包括专场、字幕、bgm 等。

工具主要用，生视频：`generate_volcano_video`，剪辑：`concatenate_videos`，修改图片：`edit_volcano_image_tool`,工具之间是 stream_processor 处理，= LangGraph ReAct 图在 agent 节点与 tools 节点之间循环，直到模型不再发起 tool_call，参数传递参考 tool 的定义，由大模型进行组装；

## 问题 2：角色一致性

主要在 skill 里面定义，如果已经有了就用 edit，没有就用 generate，有了之后使用火山的编辑接口，。

## 问题3：分镜处理

主要在《分镜脚本格式示例》定义。

时长定义：**LLM 决定** ，优先级：用户显式指定 > 分镜脚本 > 不传（服务端兜底）；

是否校验时长：没有；
