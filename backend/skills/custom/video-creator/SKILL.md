# 长视频生成工作流

## 概述

适用场景：用户需要生成有画面的视频内容，且时长超过单个片段限制（4-12秒）。

## 核心工作流程

### 第 1 步：需求分析

理解用户需求，确定以下关键信息：
- 视频总时长
- 主题与风格
- 目标受众
- 是否有指定角色（人物出镜）

如果用户没有明确指定时长，默认生成 5-10 秒的短视频。如果用户要求超过 60 秒，建议拆分为多个视频或询问是否接受分段生成。

### 第 2 步：角色注册（有角色出镜时必须，多角色一致性基础）

在分镜生图前，为每个出镜角色建立「角色 ID → 参考图」映射，写入角色注册表（storage/characters.json）：

1. 先用 `generate_volcano_image` 为每个角色生成正面角色图，等待用户确认；用户未确认前不得注册、不得进入分镜生图
2. 用户确认后调用 `register_character` 注册，入参：
   - `name`：角色名
   - `reference_image`：已确认的角色图本地路径（/storage/images/...）
   - `appearance`：稳定外观锚点（发型类别、服装类别、职业身份、标志性道具）；**不要**写身高、体型、胖瘦、肤色深浅等易触发重绘漂移的属性
   - `aliases`：用户对该角色的口语称呼（可选）
3. 记录返回的 `character_id`（如 char_a1b2c3d4），后续分镜与生图只引用 ID，不使用易混淆的自然语言称呼
4. 中途更换角色形象调用 `update_character_reference`；开始生图前用 `list_characters` 核对全部角色状态

单角色视频同样走注册流程，保证镜头级路由规则统一。

### 第 3 步：分镜脚本生成（必须，用户确认后才执行工具）

**在调用任何工具之前**，先输出完整的分镜脚本：

- 镜头序号和时长（如：镜头1：5秒）
- 每个镜头的出镜角色标注：有角色写 `【角色:character_id1,character_id2】`，无角色写 `【空镜】`
- 多角色同框镜头（≤3 人）在描述中逐个写明每个角色的空间位置（左/右/前景/后景）与相互关系（对视/背对等）
- 每个镜头的详细场景描述（包含视觉元素、动作、情绪等）
- 镜头之间的转场关系（确保故事连贯）
- 整体风格和色调要求

单镜头出镜角色超过 3 人时，必须拆分为多个镜头。输出格式示例见 references/storyboard_format.md。

**输出分镜后，等待用户确认，确认后才开始执行后续步骤。**

### 第 4 步：生成图片序列

基于分镜脚本，为每个镜头生成对应的分镜图片（所有分镜图必须先全部生成，再进入视频生成）。
先调用 `list_characters` 确认分镜中每个 character_id 均已注册；未注册的角色先回到第 2 步补齐。

**镜头级参考图路由（必须遵守）**：

| 镜头标注 | 出镜角色数 | 工具与入参 |
|---|---|---|
| 【空镜】 | 0 | `generate_volcano_image`，纯文生图 |
| 【角色:ID_A】 | 1 | `edit_volcano_image`，`image_url` = ID_A 的 reference_image |
| 【角色:ID_A,ID_B】 | 2-3 | `edit_volcano_image`，`image_urls` = 各角色 reference_image 列表 |

**多角色同框防混淆硬约束**：

1. **槽位=身份固定绑定**：`image_urls` 数组顺序即角色槽位顺序，prompt 必须按相同顺序逐个写 `【角色名】(外观锚点)`，禁止「一个男人/另一个女人」类泛指
2. **空间位置显式化**：prompt 中逐个写明每个角色的站位（左/右/前景/后景）与互相关系，避免身份互换
3. **外观锚点最小化**：只引用注册时的稳定锚点，不临时添加体型、肤色等易漂移属性；道具不得跨角色错配
4. **同框上限 3 人**：超过 3 个角色的镜头必须拆分

**禁止**：任何有角色的镜头使用 `generate_volcano_image` 重新生成，这会导致角色不一致。

**风格统一**：确保所有图片风格一致（相同主题、相似色调、统一尺寸，建议 16:9）。记录每个镜头的成品图路径，供下一步图生视频使用。

### 第 5 步：生成视频片段

基于图片和分镜描述生成视频片段：
- 使用 `generate_volcano_video` 工具，`mode="image"`
- 每个片段的提示词结合分镜描述和图片内容
- 每个片段时长根据分镜脚本确定
- 记录每个视频片段路径

### 第 6 步：拼接视频

使用 `concatenate_videos` 工具将所有片段按分镜顺序拼接为完整视频：
- 确保视频顺序严格按照分镜脚本顺序
- 验证最终视频时长是否符合用户要求
- 保持所有片段宽高比一致（建议 16:9）

### 第 7 步：质量检查

检查最终视频是否符合分镜脚本和用户要求，如有问题可重新生成部分片段。

## 执行原则

- **注册先行**：角色图未经用户确认、未通过 `register_character` 注册，不得进入分镜生图
- **分镜优先**：必须先完成分镜生成，再执行任何工具调用
- **用户确认**：分镜脚本生成后等待用户确认，确认后才开始执行
- **严格按分镜执行**：后续所有步骤严格按照分镜脚本执行
- **多角色一致性**：有角色的镜头必须按 character_id 路由参考图走 `edit_volcano_image`（单角色用 image_url，多角色同框用 image_urls），空镜才允许 `generate_volcano_image`；同框角色不超过 3 人
- **进度提示**：生成过程中实时告知用户当前进度（如："正在生成镜头1的图片..."）
