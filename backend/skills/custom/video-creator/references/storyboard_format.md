# 分镜脚本格式示例

## 标准格式

```
我将为您生成一个30秒的[主题]视频，分镜如下：

镜头1（5秒）：[详细场景描述，包含视觉元素、动作、情绪]
镜头2（5秒）：[详细场景描述]
镜头3（5秒）：[详细场景描述]
镜头4（5秒）：[详细场景描述]
镜头5（5秒）：[详细场景描述]
镜头6（5秒）：[详细场景描述]

整体风格：[统一风格描述，如：温暖写实、赛博朋克、水彩动画等]
色调：[整体色调描述，如：暖橙色调、冷蓝色调等]
```

## 角色标注规范（多角色一致性）

每个镜头标题后必须携带角色标注，character_id 来自 `register_character` 的返回值：

- 空镜：`【空镜】`
- 单角色：`【角色:char_a1b2c3d4】`
- 多角色同框：`【角色:char_a1b2c3d4,char_e5f6g7h8】`（逗号分隔，顺序即参考图槽位顺序）

约束：

- 单镜头同框角色上限 3 人，超过则拆分为多个镜头
- 多角色同框时，描述中按标注顺序逐个写明角色名、外观锚点与空间位置（左/右/前景/后景）
- 禁止用「一个男人」「另一个女人」等泛指词，必须使用注册角色名


## 示例：科技产品宣传片（30秒）

```
我将为您生成一个30秒的科技产品宣传视频，分镜如下：

镜头1（5秒）：黑色背景中，产品从远处缓缓浮现，光线从四周汇聚照亮产品轮廓，营造神秘感
镜头2（5秒）：产品正面特写，表面材质细节清晰可见，蓝色科技光效流动扫过
镜头3（5秒）：使用者的手拿起产品，背景是现代简约的办公环境，自然光
镜头4（5秒）：产品屏幕亮起，界面UI展示，操作手势特写，流畅动效
镜头5（5秒）：使用者面带微笑俯视产品，情绪：满足、专注，背景虚化
镜头6（5秒）：产品logo缓缓出现，背景光效扩散，品牌感收尾

整体风格：现代科技感，写实摄影风格
色调：冷蓝色调为主，金属质感，局部暖光点缀
```

## 示例：自然风景短片（15秒，空镜）

```
镜头1（5秒）：清晨山间薄雾，阳光穿透树梢，光束倾斜射入，树叶轻微摇动
镜头2（5秒）：溪流从石块间流过特写，水面反光闪烁，流动感强
镜头3（5秒）：山顶全景，云海翻涌，远处山峰若隐若现，静谧壮观

整体风格：自然纪录片风格，高清写实
色调：清晨暖金色
```

## 示例：多角色出镜的故事短片（20秒）

```
（前提：角色已通过 register_character 注册）
- char_xiaoyu01 小雨：齐肩黑发、米白色风衣、银色耳钉
- char_chenmo02 陈默：寸头、黑色夹克、细框眼镜

镜头1（5秒）【空镜】：城市街道，傍晚，霓虹灯开始亮起，人流穿梭
镜头2（5秒）【角色:char_xiaoyu01】：小雨走在街道上，背影，步伐轻快，手提购物袋
镜头3（5秒）【角色:char_xiaoyu01,char_chenmo02】：咖啡馆桌前两人对视，
        小雨居画面左侧穿米白色风衣，陈默居画面右侧穿黑色夹克戴细框眼镜，
        桌面两杯咖啡，暖光侧打
镜头4（5秒）【角色:char_chenmo02】：陈默侧脸特写，推了一下细框眼镜，眼神专注
镜头5（5秒）【空镜】：橱窗内的展示品特写，灯光映照，质感细腻

注：镜头1、5为空镜，使用 generate_volcano_image 生成
    镜头2、4为单角色，使用 edit_volcano_image（image_url 传对应角色参考图）
    镜头3为双角色同框，使用 edit_volcano_image（image_urls 按
    [小雨参考图, 陈默参考图] 顺序传入，与描述顺序一致）
整体风格：城市写实，电影质感
色调：暖橙色霓虹调
```
